## Differences to inspect

The API revenue is rounded to whole crores. The draft preserves the official decimal values. API net profit includes non-controlling interests; the draft uses owner-attributable profit. Provider operating profit is a derived pre-depreciation amount, and is not used as reported operating income or as the segment margin.

The releases report rounded IFRS net income of ₹33.6 billion / ₹32.0 billion and a 4.7% sequential decline. The draft's Ind AS owner-profit comparison is −4.52%. These are different definitions; do not replace one percentage with the other.

Revenue/profit use Ind AS; the separate margin comparison uses IFRS. No cross-standard conversion is inferred. Both periods within each comparison use the same accounting standard and business scope. Margin movement is measured in percentage points, not percentage growth.
