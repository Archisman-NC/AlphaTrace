# Signal Intelligence Schema

This document defines the deterministic schema contracts and quantitative methodology for the structured trading signal generation layer in AlphaTrace.

## 1. TradingSignal Schema

Every signal generated by the platform adheres to a strict `@dataclass` schema to ensure downstream compatibility with the AI reasoning layer and dashboard.

| Field | Type | Description |
| :--- | :--- | :--- |
| `ticker` | `str` | The NSE symbol (e.g., `RELIANCE.NS`). |
| `direction` | `Literal` | `LONG`, `SHORT`, or `NEUTRAL`. |
| `confidence` | `float` | Bounded score [0.0, 1.0] representing indicator alignment. |
| `signal_strength`| `Literal` | `WEAK`, `MODERATE`, or `STRONG`. |
| `causal_reason` | `str` | Deterministic explanation of indicator states. |
| `regime` | `Optional[str]`| Current market regime (Bull/Bear/Sideways). |
| `entry_price` | `float` | Latest closing price at signal generation. |
| `stop_loss` | `float` | Volatility-aware exit level (ATR-based). |
| `take_profit` | `float` | Volatility-aware target level (ATR-based). |
| `generated_at` | `str` | ISO timestamp of the signal generation. |

## 2. Directional Logic

Directional bias is determined through a "Triple Confirmation" of technical indicators.

*   **LONG**: RSI < 35 (Oversold) **AND** MACD Improving (Bullish Cross/Slope) **AND** Price testing lower Bollinger Band.
*   **SHORT**: RSI > 65 (Overbought) **AND** MACD Weakening (Bearish Cross/Slope) **AND** Price testing upper Bollinger Band.
*   **NEUTRAL**: Defaults when indicators show conflicting trends or lack an extremity edge.

## 3. Confidence Methodology

Confidence is a deterministic measure of **indicator alignment**, not a probability of success.

*   **RSI Weighting (40%)**: Distance from the 50-midpoint. More extreme RSI values increase confidence.
*   **Bollinger Weighting (40%)**: Proximity to the bands (%B). Testing the bands directly increases confidence.
*   **MACD Weighting (20%)**: Magnitude of the MACD-Signal spread relative to price.

> [!IMPORTANT]
> **Confidence != Probability**.
> In a deterministic system, confidence represents the strength of the statistical "setup" according to fixed rules. It does not account for forward-looking event risk or external variables.

## 4. Risk Framing (ATR-Based)

AlphaTrace uses a volatility-aware framing logic to provide risk context without execution commitment.

*   **Stop Loss**: `Entry - (1.5 * VolatilityProxy)` for Longs.
*   **Take Profit**: `Entry + (3.0 * VolatilityProxy)` for Longs (1:2 Risk/Reward ratio).
*   **Volatility Proxy**: Derived from the width of the Bollinger Bands ($Upper - Lower$).

## 5. Signal Strength Mapping

| Confidence | Strength | Rationale |
| :--- | :--- | :--- |
| > 0.75 | `STRONG` | Exceptional alignment across all three indicator layers. |
| > 0.50 | `MODERATE` | Clear directional bias with moderate indicator agreement. |
| < 0.50 | `WEAK` | Conflicting indicators or lack of volatility edge. |

## 6. Known Limitations

*   **No Transaction Costs**: Risk framing does not account for slippage or brokerage fees.
*   **Fixed Thresholds**: Signal triggers are currently static and do not adapt to regime-specific volatility levels.
*   **Single-Timeframe**: Signals are generated on daily data and may not reflect intraday micro-structures.
